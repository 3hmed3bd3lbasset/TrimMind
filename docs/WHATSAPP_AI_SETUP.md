# WhatsApp AI Setup & Integration Guide

This guide walks you through setting up **Evolution API**, **n8n**, **Gemini API**, and connecting them to your **TrimMind Railway Backend**.

---

## 1. Environment Variables Configuration

Set the following variables in your Railway Project or `.env` file:

```env
# Salon Backend Agent API Secret (Used to authenticate n8n requests)
AGENT_API_SECRET=trim-mind-agent-secret-key-2026

# Google Gemini API Key
GEMINI_API_KEY=AIzaSy...

# Live Salon Backend URL (Railway)
BACKEND_API_URL=https://trimmind.up.railway.app

# Live n8n Service URL (Railway)
N8N_URL=https://n8n-server-production-bdce.up.railway.app
N8N_WEBHOOK_URL=https://n8n-server-production-bdce.up.railway.app/webhook/whatsapp-webhook

# Evolution API Configuration
EVOLUTION_API_URL=https://evolution.yourdomain.com
EVOLUTION_API_KEY=your_evolution_api_global_key
```

---

## 2. Evolution API Instance Setup

1. **Deploy Evolution API**: Deploy on Railway, VPS, or Docker container.
2. **Create Instance**:
   ```bash
   curl -X POST "https://evolution.yourdomain.com/instance/create" \
     -H "apikey: your_evolution_api_global_key" \
     -H "Content-Type: application/json" \
     -d '{
       "instanceName": "trimmind_salon",
       "token": "salon_token_123",
       "qrcode": true
     }'
   ```
3. **Configure Webhook**:
   Set Evolution API webhook to send events to n8n:
   ```bash
   curl -X POST "https://evolution.yourdomain.com/webhook/set/trimmind_salon" \
     -H "apikey: your_evolution_api_global_key" \
     -H "Content-Type: application/json" \
     -d '{
       "enabled": true,
       "url": "https://n8n.yourdomain.com/webhook/whatsapp-webhook",
       "webhookByEvents": false,
       "events": [
         "MESSAGES_UPSERT"
       ]
     }'
   ```
4. **Scan QR Code**: Connect your salon's official WhatsApp Business number by scanning the QR code generated by Evolution API.

---

## 3. n8n Workflows Import

1. Open your n8n dashboard (`https://n8n.yourdomain.com`).
2. Navigate to **Workflows** -> **Import from File**.
3. Import the 4 workflow files located in `n8n/workflows/`:
   - `01_WhatsApp_Master_Router.json`
   - `02_AI_Agent_Tools_Orchestrator.json`
   - `03_Payment_Proof_Handler.json`
   - `04_Appointment_Reminders_Cron.json`
4. In n8n **Credentials**, create:
   - **Google Gemini / PaLM API Credential** with your `GEMINI_API_KEY`.
   - **Header Auth Credential** for Evolution API (`apikey: <EVOLUTION_API_KEY>`).
5. Set the global environment variables in n8n (`BACKEND_API_URL`, `AGENT_API_SECRET`, `EVOLUTION_API_URL`, `EVOLUTION_API_KEY`).
6. Activate all workflows (`Active: ON`).

---

## 4. Verification

1. Send a WhatsApp message from any personal phone to the salon number:
   `"مساء الخير، عايز اعرف اسعار الحلاقة وكباتن الصالون"`
2. Verify that Gemini replies with the natural salon greeting and lists current active services and prices dynamically retrieved from the backend!
